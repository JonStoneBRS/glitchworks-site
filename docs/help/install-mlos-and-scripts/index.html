    Guide

    Install MLOs and scripts

    From checkout to your server in a few steps, plus fixes for the errors people run into most.

    Before you start#

    • Access to your FiveM server's files: the resources folder and server.cfg.
    • The Cfx.re account that owns your server key. Assets are tied to that account.
    • A few minutes to restart your server at the end.

    Buy through Tebex#

    Checkout is handled by Tebex. During checkout you log in with your Cfx.re account, and the purchase is linked to that account.

    Use the same Cfx.re account that owns your server key. If you buy on a different account, your server can't run the asset and you'll see a "required entitlement" error.

    Download from the Cfx.re portal#

    Our paid assets are protected by Cfx's Asset Escrow, so you download them from Cfx rather than from us.

    1. Go to portal.cfx.re (formerly Keymaster) and sign in with the account you used at checkout.
    2. Open Assets > Granted Assets.
    3. Find the item and download it. You'll get a zip file.

    Add it to your server#

    1. Unzip the download. FiveM can't read zip files.
    2. Put the folder inside your server's resources folder. We suggest a [glitchworks] subfolder to keep things tidy: resources/[glitchworks]/resource_name. Folders in square brackets are just for organising; FiveM still finds everything inside.
    3. Check the folder name. It must match the resource name exactly. If your download added something like -main or (1) to the end, remove it.

    Add it to server.cfg#

    Open server.cfg and add an ensure line for each resource, using the exact folder name. Anything it depends on must start before it.

    # Dependencies first (only if the product needs them and they aren't already started)
ensure ox_lib
ensure ox_target

# Glitchworks
ensure resource_name

    Each product page and the install notes that come with it list its dependencies, for example ox_lib or ox_target.

    Check the game build#

    Many MLOs and some scripts need a newer game build. You set this in server.cfg:

    sv_enforceGameBuild 3095

    Builds such as 3095 or 3258 are common. Check each product page for the build it needs, and use that build or a newer one. Players download the matching game update the next time they join.

    Change the settings in config.lua#

    Config files are left open, even on escrowed assets, so you can set things up for your server. Open config.lua in a text editor such as VS Code or Notepad++ and change the values you need.

    Keep the quotes, commas and brackets exactly as they are. One missing comma stops the resource starting. Your server console shows the line number if something is wrong.

    Restart the server#

    Restart the whole server, not just the resource. MLOs and maps are streamed to players when they join, so restarting only the resource can leave interiors missing or broken until everyone reconnects.

    Clear your FiveM cache#

    If textures look wrong or an interior still shows the old version, clear your FiveM cache:

    1. Close FiveM completely.
    2. Press Windows + R, type %localappdata%\FiveM\FiveM.app\data and press Enter.
    3. Delete the cache, server-cache and server-cache-priv folders. Leave game-storage alone, or FiveM will download the game files again.
    4. Start FiveM and join the server.

    Troubleshooting#

    Install problems and fixes
    What you seeWhat it means and how to fix it
    "You lack the required entitlement"The asset was bought on a different Cfx.re account, or your server key isn't linked to the same account that bought it. Use a server key from the buying account, or transfer the asset to the right account in the Cfx.re portal.
    "Couldn't find resource"The folder name and the ensure line don't match. Check spelling and capitals, and remove any -main suffix from the folder.
    Interiors flicker or are missingAnother MLO is at the same location and the two are fighting, or your game build is too low. Remove or move the conflicting MLO and check the game build.
    "Oversized asset" warnings in the consoleThis is a warning, not an error. It's normal for detailed MLOs. Only worry if textures are also missing in game; if so, clear your cache.
    Falling through floors or walking through wallsThe resource isn't streaming properly. Check it started without errors, restart the whole server and check the game build.
